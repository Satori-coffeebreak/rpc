# rpc
これは、POSIXのコマンドをRustで書き直そうというプロジェクトです。
コード整形ツールはRust標準のを使っています。

ライセンスはMITです。フォークやコードの一部の利用などはお好きにどうぞ。

## 実装済みのコマンド
- echo
- pwd

## 近いうちに実装予定のコマンド
- mkdir
- touch
- cp
- mv
- rm
- cat
- less
- head
- tail
- find
- sort
- wc
- cut
- tr
- grep
- cc
- ls
- chmod
- printf

## 依存
- anyhow
